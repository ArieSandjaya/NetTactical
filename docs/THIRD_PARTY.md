# Third-party material

## Design: TemplateMo 607 "Glass Admin"
The look of the dashboard (glass cards, emerald and gold palette, rounded corners, dark and light themes) follows the free
template "TemplateMo 607 Glass Admin" (https://templatemo.com/tm-607-glass-admin). Only the visual style was reimplemented in
`src/TacticalRmm.Api/wwwroot/css/app.css` on top of this project's own markup; the template's HTML and scripts are not included
(its pages use inline styles and Google Fonts, which this project's Content-Security-Policy blocks). A credit link stays in the sidebar.
Check the template's licence terms on templatemo.com before any public redistribution.

## Fonts (SIL Open Font License 1.1)
Outfit and Space Mono, self-hosted in `src/TacticalRmm.Api/wwwroot/fonts` (woff2 from the `@fontsource` npm packages).
The licence texts are next to the font files (`OFL-Outfit.txt`, `OFL-SpaceMono.txt`).
